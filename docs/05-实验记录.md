# 05 实验记录

本文件是**移植补丁清单 + 踩坑档案**，也是最值得复用的部分。

## 1. 移植路线

原版 HIL-SERL 示例是基于官方 LeRobot 的特定版本。本项目把它移植到**本机 LeRobot 0.6.1**，
参考 [hxdoit](https://github.com/hxdoit) 的 HIL-SERL 分支（commit `8861326`），
但**所有需要现场实测的参数一律用本机实测值，不照抄**。

## 2. ★ 本地补丁清单（移植必需）

补丁文件：`patches/lerobot_local_patches.diff`。**每一处都是实机跑出来的**，不是"顺手清理"。

| # | 文件 | 改了什么 | 为什么必须 |
|---|---|---|---|
| 1 | `rl/learner.py` | **禁用回放池导出** | 官方导出代码有图像 dtype bug，一存检查点就崩 |
| 2 | `rl/learner.py` | 续训加载回放池失败时**回退空池** | 导出被禁 → `dataset` 目录不存在 → 不回退就直接终结续训 |
| 3 | `rl/actor.py` | 补回**夹爪维度** + dtype cast | 策略输出 3 维，机械臂要 4 维 |
| 4 | `rl/trainer.py` | 训练时把动作**裁到 3 维** | 与 #3 对应：夹爪这一自由度不参与学习 |
| 5 | `rl/gym_manipulator.py` | `raise_on_jump=False` | 复位跳变时不要直接抛异常 |
| 6 | `rl/gym_manipulator.py` | `finalize()` 无条件放 `finally` | 否则异常退出时 parquet footer 随机写坏（数据全废） |
| 7 | `configs/train.py` | **有检查点才拦 output_dir** | 原逻辑一刀切，actor 明明不存检查点也被拦 |
| 8 | `processor/robot_kinematic_processor.py` | IK 关节增量限幅 2 rad | 不限幅会解出离谱的关节角 |
| 9 | `robots/so_follower/so_follower.py` | `sync_read/write` 加 `num_retry=3` | USB 抖动会直接崩，重试 3 次就活下来 |
| 10 | `teleoperators/keyboard/*`（5 个文件） | 键位改造 | 用键盘做 EE 控制的接管 |

> ⚠️ 这些补丁**不要当成"环境 hack"清掉** —— 每一条都对应一个实机复现过的故障。

## 3. 踩坑档案

### 坑 1：数据集目录不可覆盖
**症状**：`FileExistsError: [Errno 17] File exists: .../push_cylinder_probe1`
**原因**：`dataset_metadata.py:794` 用 `mkdir(exist_ok=False)`，**故意拒绝覆盖**（防你几百条数据被悄悄覆盖）
**解法**：重录前先删旧目录，**或者换个新 `repo_id`**（推荐，旧数据留着对照）

### 坑 2：任务字符串写错字段
**症状**：数据集里的 task 还是上一个任务的名字
**原因**：`gym_manipulator.py:744` 用的是 **`cfg.dataset.task`**，不是 `env.task` —— 只改 `env.task` 不生效
**顺带**：训练配置的 `dataset` **没有** `task` 字段，硬加会让它解析失败

### 坑 3：奖励标注全 0
**症状**：12 集里 8 集奖励全程 0
**原因**：那些集是**跑满 `control_time_s`（20 秒）时限**自动结束的 —— 时限到了不算成功，没有任何标注
**解法**：推到位就**马上按 `y`**；实在没成功的老实留 0。真的漏标了，可以事后改 parquet 的 `next.reward`（改前先整份备份），但**该留 0 的必须留 0**

### 坑 4：actor 起不来（撞已有的检查点）
**症状**：actor 报 `FileExistsError`
**原因**：actor 和 learner 共用同一个 `validate()`，有检查点后就会拦
**解法**：给 actor 单独指 `--output_dir=<另一个目录>`（actor 不存检查点，只写日志）

### 坑 5：actor 崩了 learner 不知道
**症状**：actor 已经退出，learner 还在刷 `Push parameters to the Actor`，步数照涨
**原因**：learner 往**队列**推参数，不检查有没有人收
**解法**：停的时候**先停 actor 再停 learner**；发现 actor 没了就把 learner 也停掉重起

### 坑 6：夹爪电机串口抖动 → actor 直接退出
**症状**：`Failed to sync write @addr=55 on id=6 ... There is no status packet!` → `Unhandled exception in act_with_policy` → actor 退出
**原因**：`num_retry` 补丁只覆盖了 3 处调用（读位置×2 + 写目标位置），**configure 阶段那批配置写入走的是默认 `num_retry=0`**
**线索**：**只有夹爪（id=6）失败、前 5 个都正常** → 优先查那颗舵机的**线/插头**（接触不良）
**解法**：重插夹爪舵机线；软件上可把配置写入也加上 `num_retry`

### 坑 7：续训必须带 config_path
**症状**：`ValueError: A config_path is expected when resuming`
**解法**：`--config_path=<output_dir>/checkpoints/last/pretrained_model/train_config.json --resume=true`

### 坑 8：wandb 漏开就永远补不上
详见 [03 模型训练](03-模型训练.md) 第 2 节。**开训前确认 `wandb login` + `wandb.enable=true`。**

### 坑 9：AV1 视频按帧/按时间定位都不可靠
**症状**：`ffmpeg -ss`、`select=eq(n,...)` 抽帧抽不到，只有第 0 帧能出
**解法**：用 PyAV **顺序解码**到目标帧号，或直接用 LeRobot 数据集读取器
