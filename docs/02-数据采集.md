# 02 数据采集

HIL-SERL 的示教只负责"起手式"，但**本机参数必须先量准**，量错了后面全白跑。

## 1. 硬件

| 部件 | 说明 |
|---|---|
| 从臂 | SO-ARM101 follower，串口 `usb-1a86_USB_Single_Serial_5B79050540-if00` |
| 主臂 | SO-ARM101 leader，串口 `usb-1a86_USB_Single_Serial_5B79050094-if00` |
| 第三视角相机 | 2MP USB Camera，**必须用 `/dev/v4l/by-id/` 路径** |
| 腕部相机 | Sonix USB 2.0（本项目推物体任务不用） |

> ⚠️ **相机一律用 `/dev/v4l/by-id/`**：`video0`、`video4` 这些编号每次开机都会漂移，写死编号会导致某次训练"相机换了人"。

## 2. 三件套：开录之前必须先量

### ① 起始姿势 `fixed_reset_joint_positions`

每一集开始时手臂自动回到的姿势。**只能用手摆主臂读出来**，不能凭空写。

```bash
python -m lerobot.scripts.lerobot_teleoperate \
  --robot.type=so100_follower --robot.port=<从臂串口> --robot.id=oye_follower_arm \
  --teleop.type=so100_leader --teleop.port=<主臂串口> --teleop.id=oye_leader_arm \
  --display_data=true --fps=2
```

屏幕上会刷一张实时表，抄下 6 个数，顺序固定：
`shoulder_pan, shoulder_lift, elbow_flex, wrist_flex, wrist_roll, gripper`

**两个坑**：
1. 表头写的是 `NORM`，**但那 6 个数就是「度」**，原样抄，别换算
2. 用 `> log` 重定向会**丢掉第一行**（它是原地刷新），要看就直接看终端
3. `gripper` 跟着**主臂夹爪**走，摆好姿势时要把主臂夹爪捏到闭合再读

### ② EE 围栏 `end_effector_bounds`

限制策略能把夹爪送到哪里，防止它跑到工作区外面去。

```bash
python -m lerobot.scripts.lerobot_find_joint_limits \
  --robot... --teleop... \
  --urdf_path=<repo>/urdf/so101_new_calib.urdf \
  --target_frame_name=gripper_frame_link \
  --teleop_time_s=120 --warmup_time_s=10
```

**走法**：先把手臂摆回起始姿势，然后**只走推物体实际会用到的路径**（起始位 → 目标区，来回几遍）。

> ⚠️ 脚本把你走过的所有位置都算进盒子 —— **走越宽，盒子越大，探索空间越白圈**。这就是"围栏要尽量紧"的原因。

**z 轴可以额外收紧**：本项目把 z 上界收成「起始姿势 +5mm」、下界同理，因为推物体是**平的**，垂直方向本来就不该乱动。

### ③ 裁剪框 `crop_params_dict`

策略不吃整张 1920×1080，只吃裁剪后的 128×128。裁剪框要靠官方工具量：

```bash
# 先录 1 集"探路"（配置里 resize_size: null、crop 为空，存整图）
python -m lerobot.rl.gym_manipulator --config_path configs/record_push_cylinder_probe.json

# 再用官方工具拖框
python -m lerobot.rl.crop_dataset_roi --repo-id oye-Li-bc/push_cylinder_probe1
```

输出的格式是 `(top, left, height, width)`，直接填进配置的 `crop_params_dict`。

**拖框标准**：物体**起始位置** + **目标区** + **夹爪**都要在框里；键盘、笔记本、线材一律排除。

> 工具收尾时会额外导出一份 `<repo>_cropped_resized` 数据集，重复跑同一条命令会撞 `FileExistsError` —— **无害**，ROI 已经打印出来了。

## 3. 录制流程

```bash
bash scripts/record.sh
```

按键（本项目键位）：

| 键 | 作用 |
|---|---|
| `空格` | 接管 / 交还控制权 |
| `w/s` `a/d` `r/f` | 前后 / 左右 / 升降 |
| `o/c` | 夹爪开合 |
| `y` | **本集成功，存盘并结束** |
| `u` | 重录本集 |

## 4. ★ 标注要点（最容易白录的地方）

奖励是 **0/1 两档**，而且**只在"成功那一刻"给 1**：训练时折扣率 0.97 会把这个 1 **往回摊到前面每一帧**，策略才知道"前面这些动作是好动作"。

所以：

- **推到位后停约半秒、马上按 `y`** —— 让"成功那一刻"多留几帧
- **千万别让它跑满 `control_time_s`（默认 20 秒）** —— 跑满时限自动结束的集**没有任何成功标记**，全程 0，等于没标
- 真的没推成功的集，**老实留 0**（别手动补 1），否则等于教策略"不动 = 成功"
